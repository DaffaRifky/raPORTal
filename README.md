# raPORTal
### Sistem Pengelolaan Rapor Siswa Berbasis Web

raPORTal adalah aplikasi berbasis web yang dikembangkan sebagai Proyek Berbasis Pembelajaran (PBL) untuk membantu proses pengelolaan rapor siswa di sekolah. Sistem ini memudahkan Admin TU, Guru, Wali Kelas, dan Kepala Sekolah dalam mengelola data akademik mulai dari data master, penginputan nilai, monitoring perkembangan nilai, hingga pencetakan rapor.

---

## 📖 Tentang Proyek

Proses pengolahan rapor di banyak sekolah masih dilakukan secara manual sehingga memerlukan waktu yang lama dan berpotensi menimbulkan kesalahan pencatatan. Oleh karena itu, dikembangkan **raPORTal** sebagai sistem informasi berbasis web yang bertujuan untuk:

- Mempermudah pengelolaan data akademik.
- Membantu guru dalam menginput nilai siswa.
- Mempermudah wali kelas menyusun rapor.
- Membantu kepala sekolah memonitor perkembangan nilai siswa.
- Mengurangi kesalahan pada proses pengolahan nilai.
